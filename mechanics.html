The rules behind the numbers

How bonuses stack

Infrastructure discounts add together. The building boost multiplies what remains.

Six skills, one rule

Each Infrastructure skill checks the building’s resource-category tags. A matching skill reduces both its gold and production cost by 25%. A building can match several skills.

For example, Workshop matches Industrial and War. With both skills, it costs 50% of its base cost. When boosted, that becomes 50% × 70% = 35% of the base cost: a 65% total discount.

The catalogue assumes every matching Infrastructure skill is unlocked. Resource filters select buildings; they do not toggle your unlocked skills. Boosted figures apply only when that building’s boost requirement is met. Other discounts and whole-resource rounding are outside these figures.

Reading the tree

Arrows connect building-property prerequisites to buildings that supply those properties. A solid arrow is a single visible route; a dashed arrow means alternative buildings can satisfy that same property. Separate requirement groups must all be met; options inside a group are alternatives.

Filters hide buildings and their arrows. Select a node to see its full prerequisite groups, including buildings outside the current filters, and additional province, tome, or other gates. The tree shows building dependencies; city-level gates appear on each node.

The default list order is minimum required city level, then building tier, then name. City level comes from Town Hall requirement properties, including inherited prerequisite requirements. Building tier comes from the cost definition and can differ: an economic building’s Tier III price does not automatically require Town Hall III. Province improvements have no city-level ranking.

Sources & limits

  • Building tags, boost links, and prerequisite fields were read from the installed resource packages on 25 October 2026.
  • Boost stacking was traced through the engine bundled with the game’s resource editor. This is static analysis, not a measurement from a running save.
  • Names, icons, and boost labels use AoW4 Database at commit df99314. All 348 catalogue entries matched local definitions; all 123 exported boost flags agreed with local boost links.
  • The tree resolves required property IDs to their earliest building providers. Culture replacements can supply the same property. These are possible routes, subject to culture and other unlock conditions; choosing an alternative does not make it available to every culture.
  • Equivalent variants are merged when their bonuses, boost conditions, and building requirements match. Unused and iconless entries are omitted. Unresolved requirements remain visible in building details.
